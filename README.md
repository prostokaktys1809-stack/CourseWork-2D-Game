⚔️ Ashes of Alentania — 2D Adventure Game

Тема:Розробка 2D пригодницької гри з використанням рушія Godot  


📖 Про проєкт

«Ashes of Alentania» — це двовимірна пригодницька гра (Adventure / Action-Platformer) у стилі Pixel Art, розроблена на базі ігрового рушія Godot Engine 4.x.


🛠️ Технологічний стек

Ігровий рушій: Godot 4.5.1

Мова сценаріїв: GDScript

Контроль версій: GitHub


🚀 Реалізований функціонал

1. Фізика та Керування гравця: 
   Повноцінний рух (біг, стрибки, падіння) на основі класу `CharacterBody2D` та методу `move_and_slide()`.
   
   Механіка швидкого ривка (Dash-attack) із фреймами тимчасової невразливості.

2. Штучний інтелект ворогів (Кінцевий автомат):

   Два класи супротивників: Маг та Голем.
   
   Алгоритм патрулювання території за заданими точками.
   
   Динамічне виявлення гравця в радіусі видимості, перехід до фази переслідування та нанесення атак.

3. Система діалогів:
   
   Контекстна активація діалогового вікна при вході в зону `Area2D` взаємодії з NPC.
   
   Поетапне відображення реплік із візуальним ефектом «друкарської машинки».
   
4. Бойова система та HUD:
   
   Синхронізація механіки пошкоджень через зв'язки вузлів `Hitbox / Hurtbox` та сигнальну систему Godot.
   
   Візуалізація стану здоров'я гравця (`TextureProgressBar` у статичному `CanvasLayer`) та плаваючі шкали здоров'я (`Floating HP Bars`) над ворогами.
   
   Автоматичне перезавантаження сцени (`reload_current_scene()`) у разі критичного рівня здоров'я гравця.
   
5. Аудіосистема: Безперервне зациклене відтворення фонового атмосферного звукового супроводу через `AudioStreamPlayer`.


🎮 Керування в грі

`A` / `D` (або стрілочки `←` / `→`) — Рух вліво / вправо

`Space` — Стрибок

`Shift` — Швидкий ривок (Dash)

`LMB` (Ліва кнопка миші) — Атака мечем

`Q` — Взаємодія з NPC / Просування по діалогу
